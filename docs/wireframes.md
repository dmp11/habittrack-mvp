# Wireframes (MVP)

Текстовые вайрфреймы вместо Figma-файла. Размеры ориентированы на mobile-first (375×667, iPhone SE) с адаптацией под 412×915 (Samsung Galaxy S20). На экранах ≥640px карточки идут в два столбца, навигация перемещается в шапку.

## 1. Вход / регистрация

```text
┌─────────────────────────┐
│          ✓ HabitTrack   │
│ ┌─────────────────────┐ │
│ │ С возвращением!     │ │
│ │ Войдите, чтобы …    │ │
│ │                     │ │
│ │ Email               │ │
│ │ [ you@example.com ] │ │
│ │ Пароль   Забыли?    │ │
│ │ [ •••••••••• ]      │ │
│ │                     │ │
│ │ [    Войти          │ │
│ │ Нет аккаунта? Рег.  │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

Регистрация отличается полями «Имя (необязательно)», «Email», «Пароль» и кнопкой «Зарегистрироваться». Восстановление пароля — отдельный экран с полем email и ссылкой из письма.

## Цвета и доступность

Палитра, типографика и логотип взяты из `brandbook.txt`:

- Акцентный градиент: `#2ECC71 → #3498DB` (кнопки, большие блоки со светлым слоем), светло-голубой `#85C1E9` для второстепенных кнопок и частичных отметок.
- Основной текст: `#2C3E50`, второстепенный: `#576877`, фон: `#FFFFFF`. Для текста поверх брендовых цветов используются затемнённые производные `#2D8560` и `#2471A3` — контраст ≥ 4.5:1.
- Шрифт: Montserrat, заголовки 700/800 от 24px, основной текст 16px, межстрочный интервал 1.2/1.5.
- Тепловая карта: выполнено — зелёный `#2ECC71`, пропущено — красный `#E74C3C`, частично — `#85C1E9`, не отмечено — `#E3EBF1`, вне расписания — белый с серой обводкой.
- Логотип из папки `Logo/` размещён на экранах входа, иконка — в шапке; охранное поле сохранено.
- Минимальная высота интерактивных элементов — 44px, фокус выделен кольцом, подписи для полей и иконок дублируются текстом.
